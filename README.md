# M-A_Deal_Structuring_Assistant_DEMO
Simulates a junior M&amp;A banker's workflow: pro forma model captures financing mix (cash = after-tax interest expense, stock = dilution, synergies net of tax). Agents run accretion/dilution analysis, sweep cash/stock mix for max EPS, and cover stakeholder priorities, regulatory filings (HSR/EU/CFIUS), and negotiation posture
